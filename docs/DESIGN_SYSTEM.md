# Sistema Visual — Cruz Agenda

## Personalidade

O produto deve ser:

- Neutro
- Elegante
- Minimalista
- Moderno
- Acolhedor
- Profissional
- Simples de usar

A identidade deve funcionar para salões, studios, clínicas, designers de sobrancelhas e barbearias, sem parecer excessivamente feminina ou masculina.

## Paleta principal

| Papel | Cor |
|---|---|
| Roxo principal | `#6D4AFF` |
| Azul tecnológico | `#3977F6` |
| Rosa de destaque | `#EC4899` |
| Fundo principal | `#F7F7FB` |
| Superfície/cartão | `#FFFFFF` |
| Texto principal | `#1E1B2E` |
| Texto secundário | `#6B6878` |
| Borda | `#E8E6F0` |

## Uso das cores

### Roxo

Cor principal da marca. Usada em botões primários, navegação ativa, links e foco.

### Azul

Apoio para informações, gráficos, estados de progresso e elementos tecnológicos.

### Rosa

Usado com moderação em campanhas, destaques e pequenos detalhes. Não deve dominar o painel.

### Gradiente

`#6D4AFF → #3977F6 → #EC4899`

Permitido apenas em áreas de marca, login, hero, banners e materiais promocionais. Evitar gradiente em todos os componentes.

## Tipografia

Fonte principal: Inter.

Diretrizes:

- Títulos fortes, sem exagero
- Textos curtos e objetivos
- Números e horários com alta legibilidade
- Evitar muitas famílias tipográficas

## Formas e superfícies

- Cantos arredondados moderados
- Cartões claros
- Sombras discretas
- Bordas suaves
- Espaçamento generoso
- Ícones simples
- Animações curtas e funcionais

## Restrições visuais

Não usar:

- Excesso de rosa
- Gradientes em toda a interface
- Sombras pesadas
- Muitos estilos de botão
- Vários tipos de card para a mesma função
- Componentes duplicados com pequenas diferenças
- Telas carregadas
- Animações decorativas sem propósito

## Responsividade

Prioridade:

1. Celular
2. Computador
3. Tablet

A aplicação deve funcionar bem no navegador e poder ser adicionada à tela inicial do celular.

## Personalização do estabelecimento

Na V1, cada estabelecimento poderá configurar:

- Logo ou foto
- Nome
- Descrição
- WhatsApp
- Instagram
- Endereço
- Cor de destaque escolhida entre opções predefinidas
- Slug público

Não haverá personalização irrestrita do layout.

## Regra de consistência

Toda tela deve reutilizar os mesmos tokens de cor, espaçamento, tipografia, bordas e componentes. Novos estilos só devem ser criados quando o componente existente não atender de forma legítima.
